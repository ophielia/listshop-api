# Amounts - issues and thoughts

This document is a collection of thoughts and issues related to conversion in the ListShop

## Issues

- **Size and Modfiers**: Currently not taken into account
- **The Cheese Dilema**: Sliced cheese - modifier or separate tag.
  - In the end, the distinguising factor between a modifier and a tag is whether I go to a different place in the store to buy one.  For example, I reach for a different package for cheddar cheese, grated cheddar cheese, and sliced cheddar cheese. So the conculsion is that there are three different tags for cheddar cheese.
  - Next step - come up with a plan for handling the following case:
   - user enters cheddar cheese, but adds modifier sliced - do we swap the tag for sliced cheddar cheese?
   - remember - goal is user comfort and accuracy.  And not creating a goldberg machine.
- **Clutter**: Lots of unused fields in units.  What can we get rid of?
